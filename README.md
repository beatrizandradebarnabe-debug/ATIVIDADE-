# Sistema de Utilitários para CRM Senai

Projeto desenvolvido em PHP tem  funções auxiliares de  sistema de cadastro e atendimento de clientes.

## Funcionalidades

- Formatação de nomes
- Limpeza e validação de CPF
- Validação de e-mails
- Formatação de valores em reais
- Busca de clientes por nome
- Cálculo do total de contratos ativos
- Cálculo da média dos contratos
- Aplicação de reajustes contratuais
- Contagem de clientes ativos
- Identificação do maior contrato
- Validação dos dados básicos de clientes

## Estrutura do projeto

```text
projeto_crm/
├── utilitarios.php
└── testes/
    └── testes.php 
```   

 ## estrutura de funcionamento 


- Formatação de nomes
- Limpeza de CPF
- Validação de CPF
- Validação de CPF inválido
- Validação de e-mail
- Validação de contrato
- Busca de cliente existente
- Busca de cliente inexistente
- Aplicação de reajuste contratual 

## Como executar

No terminal, dentro da pasta projeto_crm, execute: php -s localhost:3000
